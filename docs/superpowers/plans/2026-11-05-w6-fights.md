  (`<scratchpad>/w6c_tools/mus.py hits`). Cuts go to `<scratchpad>/w6_music/<slot>.mp3` (gain and a -1 dBFS limiter baked
  in, short fade in); integration installs them over both `.ogg` and `.mp3`.
- Contacts stay test-measured on every tier (Mixamo <= 0.04 m, others <= 0.15 m). Prefer the code-only moves (tier
  invariant); new code poses go into `CineMoves.code_pose`.
- Cameras: each fight its own shot list with the Q1 helpers (low hero, dutch on the villains, push-ins, two-shots, OTS)
  plus orbit / crane / track rigs; helper shots framed in the 8 % safe area (checked by the new harness).

  subtitles and jokes that work, and the "Nobody" style.
