Master plan `docs/superpowers/specs/2026-10-29-quality-overhaul-and-phase-d-plan.md` (sections 0-2, 4, 6) and the Wave 3
design `docs/superpowers/specs/2026-10-27-phase-c-wow-days-3-5-design.md` (D3W-1 mannequin disguise, D3W-2 container

**Owner's verdict on Day 3 today:** the sneak is a plain walk, the gunfight is 2 waves of identical gunmen, the forklift
boss is hit-and-wait, nothing in the yard is interactive.

**Rules:** `scratchpad/agent_rules.md`. No screenshots, no code music (`meme_mannequin` is an owner file, silent
without it), no emoji, no gore (knockouts with stars), fictional names, Vietnamese text, "Giảm hù dọa" softens the
jump scare and the head-turn gag, never stage `.import`, the commit trailer, one commit per task.

**Resume rule:** a later agent resumes from the first unchecked task and the commits on `w3-day3`.
