# Danh sách nhạc cần tải (2026-10-25)

> **Đã gộp (2026-11-03):** danh sách đầy đủ, có trạng thái từng slot, nằm ở `docs/PHASE_E_OWNER_KIT.md`. File này giữ lại để tra lịch sử.

Game không còn nhạc tạo bằng code. Chỗ nào chưa có file thì im lặng.

**Cách làm:**
1. Tải từng bài về thư mục `Downloads`.
2. Đặt tên file bắt đầu bằng **tên chỗ dùng**, rồi dấu gạch dưới, rồi tên bài. Ví dụ: `roam_day_Take On Me.mp3`.
3. Báo Claude. Claude sẽ cắt bỏ đoạn im lặng ở đầu và đưa file vào thư mục nhạc của game.

File nhạc chỉ nằm trên máy bạn, không đưa lên git hay vào bản phát hành.

**Trạng thái: Đã tải đầy đủ 25 bài, cắt bỏ khoảng im lặng ở đầu và đồng bộ vào thư mục `music\` của game.**
