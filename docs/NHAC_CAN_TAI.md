# Nhạc cần tải (28 bài)

Tải từng bài về thư mục `Downloads`. Tên file **phải bắt đầu bằng tên ở cột "Lưu thành"**; cột đó là tên gợi ý, chép nguyên là được. Đuôi `.mp3` hay `.ogg` đều được.
Bấm link ở cột "Tìm" để mở trang tìm kiếm YouTube của bài. Tải xong hết (hoặc một phần) thì nhắn "xong": Claude cắt khoảng im lặng đầu bài, cắt độ dài cảnh phim rồi cài vào game.

Bài nào không ưng thì thay bằng bài khác, miễn tên file vẫn bắt đầu bằng tên slot.
